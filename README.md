# SANA VITA — сайт медичного центру

Адаптивний статичний сайт (HTML + CSS + JS без фреймворків), зверстаний за макетом у Figma
(курсова робота «UI/UX Design Beginning»).

## Сторінки

| Файл | Сторінка |
| --- | --- |
| `index.html` | Головна |
| `departments.html` | Відділення та пошук проблем |
| `disease.html` | Хвороба (геморой) |
| `doctors.html` | Каталог лікарів |
| `doctor.html` | Профіль лікаря |
| `prices.html` | Ціни |
| `contacts.html` | Контакти |

Кожна сторінка адаптована під десктоп (1440), планшет і мобільний (360).

## Інтерактив

- плаваючий хедер з анімованою «плашкою» активного пункту, мобільне меню;
- попапи «Звʼязатися з нами», «Зворотний дзвінок» і «Заявку прийнято», маска телефону та перевірка форм;
- каруселі (відгуки, лікарі, статті, документи), слайдер програм у першому екрані;
- інтерактивне коло цінностей на головній;
- пошук проблем і перемикання відділень, фільтр і пошук лікарів, пошук у прайсі з акордеоном;
- перегляд дипломів у лайтбоксі.

Форми працюють лише на боці браузера: дані нікуди не надсилаються, для реального сайту
потрібно підключити бекенд або сервіс форм.

## Структура

```
src/partials/   спільні хедер, футер, попапи
src/pages/      вміст сторінок
css/styles.css  стилі
js/main.js      скрипти
assets/         зображення (WebP) та іконки (SVG)
build.py        збирає src/ у готові *.html у корені
```

Після змін у `src/` виконайте `python3 build.py` — він перезапише `*.html` у корені.

## Публікація на GitHub Pages

Settings → Pages → Source: **Deploy from a branch**, гілка `main`, папка `/ (root)`.
